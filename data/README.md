## rules.json

| 字段 | 作用 |
| --- | --- |
| `retrieval` | BM25 参数（k1/b）、top_k、覆盖率门槛、最多读几篇 |
| `synonyms` | 口语/同义词扩展（"补休"→"调休"，"报销要几天内交"→"报销时限"） |
| `stopwords` | 中文停用词，降低查询噪声 |
| `followup_markers` | 判断是否为追问（"那…呢""它""上述"） |
| `claim_patterns` | 同一事项的取值抽取规则（上下文词 + 数值正则 + 负例/排除词） |
| `precedence_regex` | 识别"以本规定为准"类优先条款 |
| `scope_map` | 问题里的适用主体词 → 文档 `scope` 字段的匹配依据 |

新增业务主题时，只需在 `claim_patterns` 增加一条规则、必要时补 `synonyms`，无需改代码。
